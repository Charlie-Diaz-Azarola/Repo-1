# Repo-1

Páginas web de la Parroquia de Santo Domingo de Silos (Pinto, Madrid).

## Contenido

- `index.html`: página de inicio.
- `papa-leon-xiv/`: «La semana del Papa León XIV», un resumen semanal de sus intervenciones contrastado con los textos oficiales.
- `poblaciondiocesana/`: datos de población de la diócesis: contador, grupos de edad, indicadores y pirámides de población por municipio.
